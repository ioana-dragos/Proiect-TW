# Scenarii de utilizare

## Scenariul 1 – Rezolvarea unui quiz de informatică

- **Condiție inițială** — Elevul este autentificat și există un quiz despre structuri repetitive, cu 5 întrebări de câte un punct.
- **Pași** — Elevul selectează quiz-ul, răspunde la întrebări și trimite răspunsurile.
- **Rezultat așteptat** — Dacă elevul răspunde corect la 3 întrebări, aplicația afișează punctajul 3/5 și explicații pentru cele două răspunsuri greșite. Rezultatul este salvat în istoricul său.

## Scenariul 2 – Organizarea unui plan de studiu

- **Condiție inițială** — Elevul este autentificat.
- **Pași** — Elevul creează un plan de studiu și adaugă activitatea „Rezolvarea exercițiilor despre structuri repetitive”, cu un termen ales. După ce termină, marchează activitatea ca finalizată.
- **Rezultat așteptat** — Activitatea apare în planul de studiu, cu termenul stabilit. După reîncărcarea paginii, aceasta rămâne marcată ca finalizată.

## Scenariul 3 – Urmărirea progresului

- **Condiție inițială** — Elevul a rezolvat de două ori același quiz de informatică, obținând punctajele 3/5 și 4/5.
- **Pași** — Elevul deschide pagina de progres și consultă istoricul rezultatelor.
- **Rezultat așteptat** — Aplicația afișează ambele încercări, cu data și punctajul fiecăreia, astfel încât elevul să poată compara rezultatele.
